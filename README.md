# MyDarah

**MyDarah** is a mobile blood donation application designed to provide a one-stop platform for blood donation information and services in Malaysia.

The application helps users find blood donation centres and events, manage donation records, receive emergency blood requests & reminders and access blood donation information conveniently. 
It also provides administrative functions for managing users, events, feedback, statistics and other blood donation activities.

## 📱 Main Features
MyDarah is organised into four main service groups:

1. **Account and User Services**
2. **Donation Services**
3. **Communication and Administration**
4. **Data and Integration Services**

### 👤 Account and User Services
- User registration, login and logout
- Password reset and session management
- Donor profile management
- Hospital and organisation profile management
- Institution contact and location management
- User and staff administration
- Role application management

### 🩸 Donation Services
- Search and view blood donation centres
- View nearby donation locations
- Create and manage donation events
- Search and filter donation events
- Register for donation events
- QR code attendance and verification
- Create and manage emergency blood requests
- Match emergency requests with eligible donors
- Store and view donation records
- Track donor eligibility
- Rewards, points, badges and donor levels

### 🔔 Communication and Administration
- In-app notifications
- Unread notification tracking
- Event and emergency alerts
- Scheduled event reminders
- Blood donation analytics and reports
- Malaysian government donation statistics
- Blood group and donation data analysis
- User feedback and administrator replies
- Feedback attachment support
- About Us content management

### 💾 Data and Integration Services
- Supabase authentication and database
- Supabase file storage
- SQLite local data caching
- Online and offline data handling
- Malaysian government blood donation data integration

## Technologies Used

| Technology | Purpose |
|---|---|
| **Flutter** | Mobile application development |
| **Dart** | Main programming language |
| **Supabase** | Authentication, database and file storage |
| **SQLite / sqflite** | Local data storage and caching |
| **data.gov.my API** | Malaysian blood donation statistics |
| **HTTP** | External API communication |
| **Flutter Local Notifications** | Local event reminders |
| **Shared Preferences** | Local preferences and reminder information |
| **File Picker** | Feedback attachment selection |
| **URL Launcher** | Opening external links and attachments |
